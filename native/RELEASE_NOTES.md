# Framespace v0.36 (Quest 3 APK)

**Install:** download `framespace.apk` below and sideload it over v0.35. Your saved rooms are kept.

## Objects (179 in total)
**Storage: the full Rhino Toolbox poly cargo case range** (sizes from rhinoboxes.com.au; Bunnings rounds the 395 mm height to 400):
- Rhino cargo case 400 (CCG400): 400 x 550 x 395
- Rhino cargo case 600 (CCG600): 600 x 550 x 395
- Rhino cargo case 900 (CCG900): 900 x 550 x 395
- Rhino cargo case 1200 (CCG1200): 1200 x 550 x 395
- Rhino cargo case 1200 Low Rider (CCG1200LR): 1200 x 550 x 305

Each has an overhanging lid with a seal line, a raised lid panel the size of the real opening, Croc-Loc latches on the front (2 on 400/600/900, 3 on the 1200s), moulded end handles, ribs, base skids, 4 tie-down points, back hinges, a drain bung and the bottle opener. They're solid and stack.
